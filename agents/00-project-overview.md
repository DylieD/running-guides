## Content model (decided 2026-11-11)
No test pairs will be bought. Pages are research-based buying guides, not hands-on reviews.
- Label every page honestly: "We have not tested these shoes. This guide compiles lab test data and runner reports, with our analysis." Dylan's own mileage only where real (ASICS GT-2000 13, HOKA Speedgoat 6).
- Never use "I tested", "our review" or star ratings that imply use.
- Must add something a reader cannot get from the sources: a decision tool, comparison data, clear "who should skip this" calls, reconciling disagreements between reviewers.
- Goal: get cited by AI search and earn affiliate clicks. Google says AI visibility is still normal SEO, and commodity rehashes are what get filtered. So the value-add is the whole strategy.
- Attribute sources by name and link to them. Quote nothing beyond short phrases.

## Shared rules for every agent
1. Cite a source for every factual claim. Label confidence: VERIFIED (primary source), REPORTED (secondary or unofficial), UNVERIFIED.
2. Never fabricate first-hand experience. If Dylan has not tested a product, the page says so.
3. No publishing, sending or signing up without Dylan's yes.
4. Date every edit in the file you change and note which source triggered it.
5. Keep text plain and human. No filler.
